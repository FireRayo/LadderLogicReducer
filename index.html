Aplicación HTML5 de archivo único para capturar tablas lógicas, validar consistencia, minimizar cada salida y exportar la lógica en ASCII y en un archivo .ld de estilo LDmicro. La interfaz puede trabajar con encabezados importados como X1..Xn / Z1..Zn o con nombres por defecto E1..En / S1..Sn, y la exportación .ld usa alias compatibles con LDmicro.

Notas técnicas importantes

Modo industrial flexible: pensado para tablas de condiciones como las que usas en campo. Para cada salida, solo las filas con valor 1 aportan lógica a esa salida. Las filas con 0 no se tratan como prohibiciones globales y por eso no disparan falsos conflictos ON/OFF cuando la tabla es una lista de activación y no una tabla de verdad exhaustiva.

Modo tabla estricta ON/OFF: interpreta cada fila con salida 0 como una condición OFF explícita. Ese modo sí detecta solapamientos entre 1 y 0 y es el adecuado cuando realmente estás describiendo una tabla de verdad completa.

Minimización: la app trabaja sobre cubos lógicos, elimina redundancias, absorbe términos y fusiona implicantes. En modo estricto evita invadir estados marcados como 0. En modo industrial prioriza cubrir exactamente las condiciones ON declaradas.

Exportación LDmicro: para favorecer compatibilidad con LDmicro, el archivo .ld usa alias compatibles con el tipo de variable. Si importas X1..Xn y Z1..Zn, la app conserva esos nombres en pantalla y exporta bobinas tipo YZ1..YZn.
